# Admin Components

## Change schoolyears from the admin app bar
Render the schoolwide and differing personal schoolyear indicators as buttons. Open a persistent dialog that lists schoolyears as direct choice buttons; refresh the admin config after a successful change. Only users accepted by the schoolwide endpoint may change the schoolwide year.
