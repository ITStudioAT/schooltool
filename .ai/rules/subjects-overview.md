# Subjects Overview

## Scope subject plans to the personal schoolyear
The Subjects Overview plan, subject rows, and mappings display and edit the authenticated user's personal schoolyear. Show that personal schoolyear beside the Normalstudium/Kompaktstudium switch; never silently mix these rows with the school's active import year.
