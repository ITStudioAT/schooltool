Anmeldung

Bitte rufen Sie folgende URL auf und melden Sie sich mit Ihren Zugangsdaten an:

https://schooltool.at/admin

Falls Sie Ihr Kennwort (noch) nicht kennen, klicken Sie auf Kennwort unbekannt.

Geben Sie Ihre E-Mail-Adresse ein und klicken Sie auf Weiter.

Sie erhalten eine E-Mail mit einem Code. Geben Sie diesen Code in der SchoolTool-App ein und klicken Sie auf Weiter. Nach erfolgreicher Anmeldung gelangen Sie direkt zum Admin-Bereich.
