Auswahl von Modulen

Am Beispiel des Modultyps Aktuelle sehen Sie, wie Sie Module und die dazugehörigen Unterrichte für die automatische Stundenplanerstellung auswählen.

Module anzeigen

Klicken Sie auf Aktuelle. Darunter erscheinen die noch zu absolvierenden Module für das aktuelle Semester, beispielsweise Deutsch 2 (D2), Englisch 2 oder Ethik 2. Welche Module angezeigt werden, hängt von der ausgewählten Person ab.

Höchstens zehn Module und 30 Stunden auswählen

Für einen automatischen Stundenplan können Sie insgesamt höchstens zehn Module mit zusammen maximal 30 Stunden auswählen. Beide Grenzen gelten für die gesamte Auswahl über alle Modultypen hinweg.

Wenn Sie alle angezeigten Module des Typs Aktuelle berücksichtigen möchten, klicken Sie auf Alle auswählen. Dabei werden auch die verfügbaren Unterrichte dieser Module ausgewählt. Die Auswahl ist möglich, sofern dadurch weder die Grenze von zehn Modulen noch die von 30 Stunden überschritten wird.

Unterrichte eines Moduls individuell auswählen

Sie können stattdessen ein einzelnes Modul anklicken, zum Beispiel Deutsch 2 (D2). Es öffnet sich das Fenster Unterrichte für D2 mit den verfügbaren Unterrichten. Dort könnten beispielsweise folgende Einträge stehen:

  • D2 1Q Berg
  • D2 1S Stick
  • D2 2C Gos
  • D2 2K Gos

Wählen Sie die Unterrichte aus, die für die Stundenplanerstellung infrage kommen. Einen Unterricht, den Sie nicht berücksichtigen möchten, lassen Sie abgewählt oder wählen ihn wieder ab. Möchten Sie alle angebotenen Unterrichte zulassen, klicken Sie auf Alle auswählen und anschließend auf Bestätigen.

Mehrere Unterrichte sind Alternativen

Mehrere ausgewählte Unterrichte eines Moduls werden nicht alle gleichzeitig verplant. Sie stehen der automatischen Berechnung als Alternativen zur Verfügung. SchoolTool kann damit unterschiedliche passende Stundenpläne zusammenstellen.

Wenn Sie beispielsweise alle vier Unterrichte für D2 auswählen, darf die Berechnung einen passenden davon verwenden. Wählen Sie nur einen aus, steht für D2 ausschließlich dieser Unterricht zur Verfügung. D2 zählt dabei weiterhin als ein Modul.

Wiederholen Sie diese Schritte für die weiteren gewünschten Module. So legen Sie individuell fest, welche Module und welche Unterrichtsalternativen automatisch verplant werden dürfen.

Stundenplan erstellen

Klicken Sie abschließend auf Stundenplan erstellen. SchoolTool berechnet nun automatisch mögliche Stundenpläne auf Grundlage Ihrer ausgewählten Module und Unterrichte.
