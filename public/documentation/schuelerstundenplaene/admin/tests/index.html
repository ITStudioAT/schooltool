Tests und Kontrolle

Der Bereich Tests prüft die Studierendendaten und Modulzuordnungen für die Stundenplanung. Stundenplan-Admins können diese Prüfungen ausführen und die Ergebnisse als PDF zusammenfassen.

Voraussetzungen prüfen

Vor dem Testlauf wird geprüft, ob die notwendigen Grundlagen bereitstehen. Fehlende oder fehlerhafte Sokrates-116-Daten, fehlende benötigte aktive Fachpläne sowie fehlende oder widersprüchliche Anrechnungen können den Start verhindern. Auch eine laufende oder fehlgeschlagene Datenaktualisierung kann den Testlauf blockieren.

  1. Öffnen Sie Tests und lesen Sie die angezeigten Voraussetzungen.
  2. Beheben Sie die gemeldeten Probleme unter Importe beziehungsweise Fächer. Warten Sie einen laufenden Aktualisierungsvorgang ab.
  3. Klicken Sie auf Voraussetzungen neu prüfen.

Studierende auswählen und Tests starten

  1. Wählen Sie unter Studierende einzelne Personen oder die gewünschten Klassen beziehungsweise Semester.
  2. Mit Alle auswählen nehmen Sie alle angebotenen Personen in die Auswahl auf. Keine auswählen hebt die Auswahl auf.
  3. Starten Sie unter Tests mit Run Tests.
  4. Verfolgen Sie den Fortschritt und warten Sie auf die Ergebnisse.

Ergebnisse bearbeiten

Kontrollieren Sie die Einzelergebnisse und die Zusammenfassung. Beachten Sie besonders Fehlgeschlagene Tests und Nicht getestete Datensätze: Eine nicht getestete Person hat den Test nicht automatisch bestanden.

  1. Lesen Sie bei einem auffälligen Ergebnis die betreffende Person und den gemeldeten Daten- oder Modulunterschied ab.
  2. Prüfen Sie die zugrunde liegenden Studierendendaten, Anrechnungen, Fachpläne und Zuordnungen.
  3. Korrigieren Sie die Ursache, prüfen Sie die Voraussetzungen erneut und wiederholen Sie den Test für die betroffenen Personen.

Testübersicht als PDF

Mit PDF erstellen erzeugen Sie eine Übersicht der Testergebnisse, etwa für die gemeinsame Nachkontrolle.

Die Tests prüfen Planungsvoraussetzungen und Modulzuordnungen. Sie sind keine Prüfungsverwaltung für Studierende. Ein erfolgreicher Test ersetzt auch nicht die Kontrolle des konkret erstellten Stundenplans auf Termine und Überschneidungen.
