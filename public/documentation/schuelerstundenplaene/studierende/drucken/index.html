Stundenplan drucken

Laden Sie Ihren Stundenplan als PDF herunter und drucken Sie die Datei aus.

1. PDF herunterladen

  1. Öffnen Sie den gewünschten Plan im Bereich Manueller Stundenplan, etwa über Mein gespeicherter Stundenplan → Eigenen öffnen.
  2. Prüfen Sie, ob alle gewünschten Unterrichte angezeigt werden. Sichern Sie neue Änderungen mit Speichern, wenn Sie diesen Stand später wieder bearbeiten möchten.
  3. Klicken Sie neben Speichern auf PDF und warten Sie auf den Download.
  4. Öffnen Sie die heruntergeladene Datei über die Downloadanzeige Ihres Browsers oder Ihren Downloadordner.

PDF lädt den angezeigten Plan herunter. Um ihn später in der App weiterzubearbeiten, klicken Sie zusätzlich auf Speichern.

2. Datei kontrollieren und drucken

  1. Kontrollieren Sie die PDF vor dem Druck. Sie enthält unter anderem Allgemeine Informationen, die Studienauswahl und den Stundenplan.
  2. Klicken Sie in der PDF-Ansicht auf das Drucksymbol oder drücken Sie unter Windows Strg+P.
  3. Wählen Sie Drucker, Seiten und Kopien. Prüfen Sie die Druckvorschau. Wird etwas abgeschnitten, wählen Sie die Anpassung an die Seitengröße.
  4. Starten Sie den Druck. Sie können die PDF auch ohne Papierausdruck auf Ihrem Computer aufbewahren.
Buchen nicht vergessen!

Der Stundenplan ersetzt keine Anmeldung zu Lehrveranstaltungen. Es gelten Ihre offiziellen Buchungen und die veröffentlichten Termine.

Wenn keine PDF erscheint

Prüfen Sie die Downloads Ihres Browsers. Fehlt die Datei, prüfen Sie die Internetverbindung und klicken Sie erneut auf PDF. Drucken Sie die PDF statt der Webseite.

Laden Sie die PDF nach Änderungen am Plan erneut herunter.
