Stundenplan der Lehrperson öffnen

Sie können den bereitgestellten Plan Ihrer Lehrperson öffnen und anpassen.

Vorlage öffnen

  1. Gehen Sie nach der Anmeldung zur Übersicht.
  2. Wählen Sie die Karte Stundenplan der Lehrperson.
  3. Klicken Sie auf Vorlage öffnen.
  4. Der Plan öffnet sich direkt unter Manueller Stundenplan. Prüfen Sie die enthaltenen Module, Unterrichtsangebote und Termine.

Vorlage an Ihre Planung anpassen

Sie können Unterrichte ergänzen oder Module entfernen und andere Unterrichtsangebote wählen. Folgen Sie dafür dem Kapitel Stundenplan bearbeiten.

Klicken Sie danach auf Speichern. Ihren Plan finden Sie später unter Mein gespeicherter Stundenplan → Eigenen öffnen.

Vorlage und eigener Plan sind getrennt

Ihre Änderungen betreffen nur Ihren eigenen Plan. Vorlage öffnen lädt den Plan der Lehrperson; Eigenen öffnen lädt Ihren gespeicherten Plan.

„Noch kein Stundenplan bereitgestellt“

In diesem Fall bleibt die Karte deaktiviert. Bitten Sie die zuständige Lehrperson, einen Plan für Sie bereitzustellen. Alternativ können Sie über Leer beginnen selbst eine Planung starten.

Speichern Sie Ihre Änderungen, bevor Sie einen anderen Plan öffnen.
