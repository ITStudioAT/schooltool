Stundenplan bearbeiten

Unter Manueller Stundenplan bearbeiten Sie eine Vorlage, Ihren gespeicherten Plan oder einen automatisch erstellten Vorschlag.

Für Computer und Laptop gedacht

Nutzen Sie die App am Computer oder Laptop mit Maus und Tastatur. Auf dem Handy sind die Tabellen und Auswahlfelder schwer zu bedienen. Die App läuft im Browser; eine Installation ist nicht nötig.

Unterricht zum Plan hinzufügen

  1. Wählen Sie im Modulkatalog Studierenden Module für die Ihnen zugeordneten Module oder Alle Module für das gesamte verfügbare Angebot.
  2. Öffnen Sie die gewünschte Modulgruppe und klicken Sie auf ein Modul.
  3. Im Dialog Unterrichte für … sehen Sie die verfügbaren Unterrichtsangebote. Prüfen Sie Termine, Dauer, Lehrpersonenkürzel und Hinweise.
  4. Markieren Sie nur die Angebote, die Sie in Ihren Plan aufnehmen möchten.
  5. Klicken Sie auf Verplanen. Der Unterricht erscheint zu seinen vorgegebenen Zeiten im Stundenplan.

Abbrechen schließt die Auswahl ohne Änderungen. Bereits hinzugefügte Angebote sind mit Verplant markiert.

Module entfernen oder Angebote austauschen

  1. Suchen Sie das Modul oben unter Ausgewählte Module.
  2. Klicken Sie auf das Kreuz neben dem Modul. Dadurch entfernen Sie dessen Unterrichte aus dem aktuellen Plan.
  3. Wenn Sie nur eine andere Unterrichtsvariante möchten, öffnen Sie das Modul anschließend erneut im Katalog, wählen das passende Angebot und klicken auf Verplanen.
  4. Prüfen Sie die aktualisierte Tabelle und speichern Sie den gewünschten Stand.

Die Unterrichtszeiten sind festgelegt. Für einen anderen Termin wählen Sie ein anderes Angebot.

Hinweise und Überschneidungen beachten

  • Rote Angaben in Klammern bei Terminen kennzeichnen Überschneidungen mit anderen Unterrichten. Prüfen Sie diese, bevor Sie den Plan übernehmen.
  • Nicht vorgesehen! weist auf Module außerhalb der vorgesehenen Auswahl hin. Klären Sie im Zweifel, ob das Modul zu Ihrem Studium passt.
  • Beachten Sie alle Termine eines Angebots, insbesondere zweiwöchentliche Einheiten, Blocktermine und Fernunterricht.

Bearbeitung abschließen

Klicken Sie nach der Bearbeitung auf Speichern. Mehr dazu unter Speichern und später wieder öffnen.
