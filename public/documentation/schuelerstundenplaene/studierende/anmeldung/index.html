Anmelden

Verwenden Sie die E-Mail-Adresse, die Ihre Schule für Sie hinterlegt hat. Für die Anmeldung ohne Kennwort brauchen Sie Zugriff auf dieses Postfach.

1. Schule wählen und E-Mail-Adresse eingeben

  1. Öffnen Sie die SchoolTool-Startseite.
  2. Wählen Sie Ihre Schule. Bei vielen Schulen nutzen Sie Schule suchen … und klicken auf Weiter. Ist die richtige Schule bereits ausgewählt, fahren Sie direkt fort.
  3. Klicken Sie bei der Karte SEPP auf Starten.
  4. Prüfen Sie im Login-Bereich die Schule. Über Schule ändern können Sie sie wechseln.
  5. Geben Sie Ihre E-Mail-Adresse im Feld E-Mail ein. Fahren Sie mit oder ohne Kennwort fort:

Direkter Anmeldelink: Über einen Link Ihrer Schule oder die direkte Anmeldung gelangen Sie oft gleich zum Login-Bereich. Falls Verfügbare Schulen erscheint, wählen Sie zuerst Ihre Schule. Bei vielen Schulen hilft Schule suchen (Name oder Kürzel).

Bereits angemeldet? Dann gelangen Sie direkt zur Stundenplanübersicht.

2. Mit bekanntem Kennwort anmelden

  1. Klicken Sie auf Weiter mit Kennwort.
  2. Geben Sie Ihr Kennwort im Feld Passwort ein.
  3. Klicken Sie auf Anmelden. Nach erfolgreicher Anmeldung gelangen Sie zu Ihrer Stundenplanübersicht.

Erste Anmeldung oder Kennwort vergessen

Wenn Sie noch kein Kennwort haben oder es vergessen haben, melden Sie sich mit einem E-Mail-Code an:

  1. Wählen Sie nach der Eingabe Ihrer E-Mail-Adresse Weiter ohne Kennwort.
  2. Öffnen Sie Ihr E-Mail-Postfach und suchen Sie die Nachricht mit dem sechsstelligen Code. Prüfen Sie gegebenenfalls auch den Spamordner.
  3. Geben Sie den Code auf der Anmeldeseite ein und klicken Sie auf Code bestätigen.
  4. Nach erfolgreicher Anmeldung können Sie über Kennwort ändern ein eigenes Kennwort festlegen.

Hilfe bei Anmeldeproblemen

  • E-Mail-Adresse nicht bekannt: Kontrollieren Sie Schule, Schreibweise und verwendete Adresse. Kontaktieren Sie die Schule, wenn Ihre Adresse nicht hinterlegt ist.
  • Keine E-Mail erhalten: Prüfen Sie Posteingang und Spamordner sowie die eingegebene Adresse. Wenden Sie sich bei anhaltenden Problemen an die Schule.
  • Code ungültig oder abgelaufen: Klicken Sie auf Zurück und fordern Sie über Weiter ohne Kennwort einen neuen Code an.
  • „Login mit Code derzeit nicht möglich“: Der Code-Zugang steht momentan nicht zur Verfügung. Verwenden Sie Ihr vorhandenes Kennwort oder wenden Sie sich an die Schule.

Nach der Arbeit abmelden

Sichern Sie Änderungen zuerst mit Speichern. Klicken Sie danach oben auf Abmelden oder öffnen Sie das Menü rechts oben und wählen Sie dort Abmelden. Das ist besonders an gemeinsam verwendeten Computern wichtig.

Für Computer und Laptop gedacht

Nutzen Sie die App am Computer oder Laptop mit Maus und Tastatur. Auf dem Handy sind die Tabellen und Auswahlfelder schwer zu bedienen. Die App läuft im Browser; eine Installation ist nicht nötig.
