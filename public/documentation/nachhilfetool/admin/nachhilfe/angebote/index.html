Angebote

Unter dem Menüpunkt Angebote können alle Nachhilfe-Angebote der Schule verwaltet werden.

Bedeutung der Symbole in der Übersichtsliste​

Dieses Angebot wurde noch nicht freigegeben (=genehmigt).
Daneben steht die E-Mail-Adresse der Mentor:in, die das Angebot freigeben sollte.

Dieses Angebot wurde bereits freigegeben (=genehmigt).
Daneben steht die E-Mail-Adresse der Mentor:in, die das Angebot freigegeben hat.

Dieses Angebot ist offline (niemand kann das Angebot sehen).

Dieses Angebot ist online (jeder kann das Angebot sehen).

Informationen zum Angebot​

Sobald ein Angebot angeklickt ist, erhält man detaillierte Informationen zum Angebot:

Genehmigen​

Das Angebot wird genehmigt.

✉️ Die Schüler:in wird über diesen Vorgang per E-Mail verständigt.

info

Eigentlich wäre das Genehmigen die Aufgabe der Mentor:innen.

Nicht genehm.​

Die Genehmigung des Angebotes wird entzogen.

✉️ Die Schüler:in wird über diesen Vorgang per E-Mail verständigt.

Online​

Das Angebot wird online gestellt (jede:r kann das Angebot sehen).

Offline​

Das Angebot wird offline gestellt (niemand kann das Angebot sehen).

Sperren / Entsperren​

Mit diesem Menüpunkt kann ein:e Schüler:in gesperrt werden.
Danach kann sich die Schüler:in nicht mehr am System anmelden.

✉️ Die Schüler:in wird über diesen Vorgang per E-Mail verständigt.

Mit diesem Menüpunkt kann ein:e gesperrte:r Schüler:in wieder entsperrt werden.
Danach kann sich die Schüler:in wieder normal am System anmelden.

✉️ Die Schüler:in wird über diesen Vorgang per E-Mail verständigt.

Löschen​

Angebote, für die es noch keine Anfrage anderer Schüler:innen gegeben hat, können gelöscht werden. Klicken Sie dazu auf Löschen

Klicken Sie erneut auf Löschen
