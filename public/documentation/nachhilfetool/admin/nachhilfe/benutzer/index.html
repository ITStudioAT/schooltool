Benutzer

Unter dem Menüpunkt Benutzer können Schüler:innen, die beim Nachhilfetool angemeldet sind, verwaltet werden.

Benutzer hinzufügen​

Normalerweise melden sich Schüler:innen selbständig beim Nachhilfetool an.

Es ist aber auch möglich, dass ein:e Nachhilfetool-Administrator:in eine:n neue:n Schüler:in hinzufügt.

Klicken Sie dazu auf Hinzufügen.

Jetzt können folgende Datenfelder ausgefüllt werden:

  • Nachname
  • Vorname
  • E-Mail
  • Schulklasse
  • Geschlecht

Weitere Aktionen​

Außerdem sind folgende weitere Aktionen für Benutzer möglich:

  • Ändern
  • Sperren / Entsperren
  • Bestätigen
  • Löschen

Ändern​

Mit diesem Menüpunkt können die bestehenden Benutzerdaten geändert werden.

Sperren / Entsperren​

Mit diesem Menüpunkt kann ein:e Schüler:in gesperrt werden.
Danach kann sich die Schüler:in nicht mehr am System anmelden.

✉️ Die Schüler:in wird über diesen Vorgang per E-Mail verständigt.

Mit diesem Menüpunkt kann ein:e gesperrte:r Schüler:in wieder entsperrt werden.
Danach kann sich die Schüler:in wieder normal am System anmelden.

✉️ Die Schüler:in wird über diesen Vorgang per E-Mail verständigt.

Bestätigen​

Mit diesem Menüpunkt kann eine neu registrierte Schüler:in, die auf die Freigabe wartet, freigeschaltet werden.
Danach kann sich die Schüler:in am System anmelden.

Löschen​

Mit diesem Menüpunkt kann ein:e Schüler:in gelöscht werden.

Das Löschen muss noch einmal bestätigt werden.
